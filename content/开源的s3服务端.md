## silo

> fork 自 `minio` 并做了优化

```shell
mkdir -p /data/silo/data
docker run \
   --restart always \
   -p 9000:9000 \
   -p 9001:9001 \
   --name silo \
   -v /data/silo/data:/data \
   -e "MINIO_UPDATE=off" \
   -e "MINIO_ROOT_USER=ROOTNAME" \
   -e "MINIO_ROOT_PASSWORD=CHANGEME123" \
   pgsty/silo:distroless server /data --console-address ":9001"
```

相关客户端基本都是兼容的
